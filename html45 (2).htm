Grammar — Plurals & Can / Can't (Magic Park)

Learn the rules with pictures, practise many examples (60 minutes). Follow the boxed rule and do the tasks.

Plural Rules — Visual Box

Group A: Add -s. Example: Frog → Frogs; Monkey → Monkeys.

Group B: Add -es to words ending in sounds like -s, -sh, -ch, -x, -o. Example: Match → Matches; Fox → Foxes.

Group C: Consonant + y: drop the y, add -ies. Example: Fly → Flies; Cherry → Cherries.

Group D: Vowel + y: just add -s. Example: Toy → Toys; Monkey → Monkeys.
